# IT Security Policy

## Passwords
Passwords must be at least fourteen characters long and must not be reused across systems. Use the company
password manager to generate and store them. Passwords are never shared, including with IT staff.

## Multi-factor authentication
Multi-factor authentication is mandatory for email, the VPN and every system holding customer data. Use the
authenticator app; SMS codes are only allowed as a temporary fallback.

## Laptop encryption
All laptops must use full-disk encryption, which IT enables before handing a device over. Never disable
encryption or install software that bypasses it.

## Reporting incidents
Report a lost or stolen device, a suspected phishing email or any other security incident to the security
team within one hour at security@example.com or via the incident form. Do not try to investigate yourself.

## VPN access
Connect to vpn.example.internal with the company VPN client. Access to production networks additionally
requires membership in the PROD-ACCESS group, which is reviewed every quarter.
